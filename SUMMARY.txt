                        TRANSACTION TABLE SCHEMA
================================================================================

Column Name              Type            Purpose
─────────────────────────────────────────────────────────────────────────────
id                      INTEGER         Primary Key
user_id                 INTEGER         Foreign Key → User
booking_type            VARCHAR(20)     'movie' or 'bus'
booking_id              INTEGER         Reference to booking
amount                  FLOAT           Payment amount (PHP)
currency                VARCHAR(10)     Currency code
payment_method          VARCHAR(50)     'gcash', 'paymaya'
payment_status          VARCHAR(20)     pending/completed/failed
paymongo_source_id      VARCHAR(255)    PayMongo source ID (UNIQUE)
paymongo_payment_id     VARCHAR(255)    PayMongo payment ID
transaction_reference   VARCHAR(50)     TXN-* unique reference (UNIQUE)
error_message           TEXT            Error details
error_code              VARCHAR(50)     PayMongo error code
created_at              DATETIME        Creation timestamp
updated_at              DATETIME        Last update timestamp
completed_at            DATETIME        Completion timestamp

================================================================================

User clicks "Pay with GCash/PayMaya"
           ↓
Create PayMongo Source
  ├─ Create Transaction (pending)
  ├─ Call PayMongo API
  └─ Get checkout URL
           ↓
Redirect to PayMongo Checkout
           ↓
User Completes E-Wallet Payment
           ↓
Success Callback
  ├─ Verify with PayMongo
  ├─ Update Transaction (completed/failed)
  ├─ Update Booking
  └─ Update Seat Availability
           ↓
Show Receipt to User
           ↓
Transaction Logged in Database
           ↓
Available in Admin Dashboard

================================================================================
                        TRANSACTION STATUSES
================================================================================

PENDING (🟡 Yellow)
  └─ Awaiting user to complete payment
  └─ PayMongo source created
  └─ Waiting for checkout redirect

COMPLETED (🟢 Green)
  └─ Payment successful
  └─ Verified by PayMongo
  └─ Booking confirmed
  └─ Seats updated

FAILED (🔴 Red)
  └─ Payment declined
  └─ Error occurred
  └─ Details logged
  └─ User can retry

CANCELLED (⚪ Gray)
  └─ User cancelled
  └─ Transaction abandoned
  └─ Can create new one
