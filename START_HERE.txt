================================================================================
                        PAYMENT FLOW
================================================================================

1. User selects movie/bus booking
2. Proceeds to checkout page
3. Selects payment method (GCash or PayMaya)
4. Clicks "Pay Now"
5. Backend creates Transaction (pending)
6. PayMongo API generates checkout URL
7. User redirected to PayMongo e-wallet page
8. User completes payment
9. User redirected back to success page
10. Backend verifies payment with PayMongo
11. Transaction updated (completed)
12. Receipt displayed to user
13. Seat availability updated
14. User receives confirmation

Time: ~2-3 minutes per transaction

================================================================================
                        TROUBLESHOOTING
================================================================================

Problem: "ModuleNotFoundError: No module named 'requests'"
Solution: pip install -r requirements.txt

Problem: "Database is locked"
Solution: Delete ticketing.db and run: python init_db.py

Problem: "PayMongo API error"
Solution: 
  1. Check .env for correct API keys
  2. Verify internet connection
  3. Check PayMongo API status

Problem: "Payment not showing receipt"
Solution:
  1. Check browser console for errors
  2. Check application logs
  3. Verify redirect URLs in code

Problem: Can't access admin dashboard
Solution:
  1. Check if logged in as admin
  2. Verify admin permissions
  3. Check application logs

More solutions in TROUBLESHOOTING.md
